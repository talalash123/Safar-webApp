Safar Web ApplicationExecutive SummarySafar is an enterprise-grade railway management and booking platform designed to modernize rail travel. Built on .NET 8.0, the system integrates artificial intelligence directly into core business logic to handle dynamic pricing, smart seating arrangements, and automated customer support. The architecture is designed for high scalability, supporting thousands of concurrent transactions with sub-millisecond latency.Core System FeaturesCustomer PortalFrictionless Route Discovery: Real-time search with dynamic ML-driven pricing.Interactive Seat Mapping: Visual tier-based selection across Economy, Business, and Executive classes.Digital Ticketing: Automated PNR generation accompanied by scannable QR codes.Smart Checkout: Demographic-aware booking flow integrated with an algorithmic seating engine.Administration ConsoleFleet Management: Complete oversight of rolling stock and bogey configurations.Dynamic Scheduling: Route and calendar management with segment-specific base pricing.Manifest Generation: Automated passenger manifests highlighting special assistance requirements.System Analytics: Real-time visibility into system load, revenue, and active AI price modifiers.Technology StackLayerTechnologyBackend Core.NET 8.0 SDK, ASP.NET Core, C# 11.0FrontendRazor Pages, Bootstrap 5.3, HTML5/CSS3, jQueryDatabaseMongoDB 5.0+ (Primary NoSQL), Entity Framework CoreMachine LearningML.NET (FastTree Regression, SdcaMaximumEntropy)InfrastructureDocker, GitHub Actions (CI/CD)Artificial Intelligence IntegrationsDynamic Pricing Engine: Utilizes gradient boosting decision tree regression to adjust fares based on real-time supply, demand, and temporal factors.Constraint-Based Seating: A heuristic engine that assigns seating based on demographic safety and cultural norms, such as proximity requirements for seniors and solo female travelers.Intent-Driven Support: An NLP-powered chatbot handling Tier-1 customer support inquiries via text classification.Getting StartedPrerequisites.NET 8.0 SDKMongoDB Community Server (v5.0+) or
